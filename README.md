## 🧴 ¿Qué es MyLook?

**MyLook** Somos una plataforma especializada en la gestión de citas para el sector de la belleza, conectamos a personas con salones, estilistas y expertos en belleza, de forma rápida, práctica y segura, ya sea un corte de cabello, un facial o un diseño de uñas, todo está en un solo lugar y disponible cuando tú lo necesites.

---

## ✨ Características principales

- Agendamiento de citas.
- Registro e inicio de sesión de usuarios.
- Registro e inicio de sesión de negocios.
- Panel de gestión de negocios.
- Panel de gestión de usuarios.
- Sistema de calificación de negocios.
- Sistema de notificaciones

---

## 🚀 Tecnologías utilizadas

- **Framework:** Laravel 11
- **Backend:** PHP
- **Base de datos:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Libreria Principal:** FullCalendar
